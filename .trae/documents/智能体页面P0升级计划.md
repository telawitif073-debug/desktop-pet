# 智能体页面 P0 升级计划（手机端 + 平台 Web）

## Context（背景）

用户原始规格是一份全栈「智能体管理平台」（10 模块 / 15+ 后端组件 / 11 张表）。经确认：**本迭代 P0 最小闭环**，**两端都要**（手机 RN + 平台 Web），**多智能体协同后续放后端编排**（P1）。

现状（已探查）：
- 手机端：`LlmProfile = 智能体`（types.ts），`ProfileManager`（ChatScreen.tsx 内 Modal）已支持 列表/新增/编辑/删除/切换/绑定形象；对话按 `llmActiveProfileId` 隔离；`appStore.switchProfile` 切档案同时切形象；`sync.ts` 上传 `llmProfiles`；`llm.ts buildSystemPrompt` 组装人设。
- 平台后端：`agents` 模块（agent_assets 表 + CRUD/审核/下载，公开资源市场用）；`sync` 模块（user_sync_data jsonb，`sync.service.ts` 已做 `llmProfiles[].apiKey` 加密/解密，其余字段透传）；`uploads/storage.service.ts` 文件服务；`auth` JWT。
- 平台 Web：`platform/frontend/src/pages/`（Auth/Upload/Settings/ResourceList/ResourceDetail/Profile/Admin），`api.ts` 已有接口封装，React（vite 5174）。

关键结论：**个人智能体（LlmProfile）走已有 sync 通道**（jsonb 透传 + apiKey 加密已具备），**公开智能体市场走 agents API**（已有 CRUD）。本迭代只动个人智能体管理，不扩公开市场。

## 范围（P0）

不做的事（列为 P1/P2 路线图）：JSON/YAML 导入导出、Schema 校验、依赖识别与补全向导、自动替换、多智能体编排（后端）、凭证管理扩展、调试与发布。

本次交付：
1. `LlmProfile` 扩展字段（手机端类型 + 表单 + 聊天运行时联动）
2. 手机端 ProfileManager UI 扩充（搜索 / 复制 / 启停 / 新字段表单）
3. 平台 Web 新增「智能体」管理页（列表/搜索/启停/新增/编辑/删除/绑定形象，走 sync API）
4. 后端零改动优先；若 sync DTO 白名单拦截则补字段

## 数据模型（types.ts，手机端）

`LlmProfile` 新增可选字段：

```ts
avatar?: string;              // 头像（emoji 或首字，表单不填默认取 name 首字）
intro?: string;               // 简介
domainTags?: string[];        // 领域标签（医疗/训练/内容/陪伴/电商，单选或自填）
role?: string;                // 角色（医生/训练师/经纪人/管家…可选）
style?: string;               // 风格（温柔/毒舌/专业/搞笑/简短…）
greeting?: string;            // 欢迎语
exampleQuestions?: string[];  // 示例问题（换行分隔录入）
enabled?: boolean;            // 启停，默认 true
```

## 手机端改动

1. **types.ts**：加以上字段（可选，向后兼容旧数据）。
2. **appStore.ts**：
   - `switchProfile`：目标档案 `enabled === false` 时拒绝切换（保持当前，可返回 false/忽略）。
   - 新增 action `toggleProfileEnabled(id)`：停用当前激活档案时自动切到第一个 enabled 档案（并同步切形象）；停用非当前不做其他动作。
   - `duplicateProfile(id)`：复制档案（新 id `p-*`，apiKey 一并复制，name 加「副本」）→ 加入列表并设为激活。
   - PERSIST_KEYS 已含 llmProfiles，无新增。
3. **ChatScreen.tsx（ProfileManager）**：
   - List 顶部加搜索框（按 name/domainTags 过滤）。
   - 每行：名称+领域标签 chip+当前标记+模型+绑定形象名；右侧按钮：编辑 / 删除 / 复制 / 启停 Switch。
   - 编辑/新增表单新增字段：头像（可选）、简介、领域标签（预设 chip 单选+自定义）、角色、风格、欢迎语、示例问题（TextInput multiline 换行分隔）。
   - 激活档案禁停（Switch 灰色禁止）或提示「先切换智能体」。
   - 空列表引导文案沿用。
4. **llm.ts buildSystemPrompt**：人设后追加 `role`/`style`（如「你的角色是{role}，说话风格{style}」），`greeting` 不进 system（供 UI 展示）；示例问题在 ProfileManager 表单内展示/编辑，不进运行时。
5. **sync.ts**：`uploadNow('config')` 载荷已整包传 llmProfiles，新字段自动带上；无需改。
